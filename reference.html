Skill map: what a specialist should know

  • Foundations: networking, Linux, Windows, one scripting language, cryptography basics
  • Defence: logging, SIEM, EDR, hardening, vulnerability management, incident response
  • Offence: recon, web and network testing, Active Directory, privilege escalation, reporting
  • Modern infrastructure: cloud IAM, containers, infrastructure as code, identity
  • Governance: risk, frameworks, compliance, business continuity
  • Professional: clear writing, explaining risk to non-experts, ethics and law, constant learning

Topics to study after the roadmap

Active Directory (Windows networks)

AD stores users, computers and policies for a company. Learn domains, Kerberos, NTLM, groups and Group Policy. Common attacks: password spraying, Kerberoasting, abuse of over-privileged accounts. Defences: tiered admin accounts, long service-account passwords, monitoring logon events (4624/4625, Kerberos 4768/4769). Build a free AD lab with Windows Server evaluation plus a Windows client.

Cloud security

Shared responsibility, IAM least privilege, MFA on root/admin, no public storage, central logging (e.g. CloudTrail/Activity Logs), key management. Practise with a free-tier account and deliberately vulnerable cloud labs.

Malware analysis basics

Always inside an isolated VM with a snapshot. Static: hashes, strings, file type, imports. Dynamic: run in a sandbox and watch processes, files, registry and network. Report indicators of compromise.

Digital forensics

Order of volatility (RAM first, disk later), forensic imaging, hashing to prove integrity, chain of custody, building a timeline from logs and file times.

Containers and DevSecOps

Docker images, running as non-root, no secrets in images, scanning dependencies and images, scanning code in CI pipelines.

Frameworks

NIST CSF (Govern, Identify, Protect, Detect, Respond, Recover), CIS Controls (prioritised safeguards), ISO 27001 (management system), OWASP Top 10 (web risks), MITRE ATT&CK (attacker behaviour).

Habits that make you better

  • One lab or write-up per week, even small ones
  • Read one security news item daily and explain it in two sentences
  • Re-do old labs without notes to test real recall
